## 🤔 為什麼需要這個系統

### 交通震波是什麼？

您一定有過這種經驗：
- 高速公路上明明沒有車禍，卻突然塞車
- 塞了一段時間後又莫名其妙順暢了
- 這就是「交通震波」

### 傳統問題

**駕駛者的困擾：**
- 導航軟體只能告訴您「現在」哪裡塞車
- 但無法預測「未來」會不會塞車
- 等發現塞車時，已經來不及改道了

**管理者的挑戰：**
- 只能看到塞車發生，無法提前預防
- 不知道應該採取什麼管制措施
- 缺乏科學依據來評估措施效果

### 我們的解決方案

**預測未來，而非只看現在：**
- 系統可以預測未來60分鐘的交通狀況
- 在震波形成前就發出預警
- 給您足夠的時間改變計畫

**科學理論支撐：**
- 我們將地震學的震波傳播理論應用到交通流
- 發現交通震波以6.7 km/h的速度向後傳播
- 準確率達到87%

**AI輔助決策：**
- 17種深度學習模型協同運作
- 分析歷史案例，提供最佳建議
- 讓管理更科學、更有效

## 💡 核心技術創新

### 1️⃣ 創新的震波檢測理論

**借鑑地震學研究：**

我們發現交通震波的傳播模式，與地震波非常相似。參考美國Indiana州的研究，我們發現：
- 交通震波會以固定速度（6.7 km/h）向後傳播
- 通過監測多個測站的速度變化，可以精確捕捉震波
- 這就像地震站網監測地震波一樣

**三級預警系統：**
- 🟢 **輕微震波**：速度下降6-18 km/h → 提醒駕駛注意減速
- 🟡 **中等震波**：速度下降18-30 km/h → 建議考慮改道
- 🔴 **嚴重震波**：速度下降超過30 km/h → 強烈建議改道或延後出發

**準確率87%：**

我們分析了59個真實震波案例，系統能正確識別87%的震波事件，誤報率僅16%。

### 2️⃣ MT-STNet深度學習預測引擎

**同時預測三項交通指標：**

傳統系統只能預測單一指標（如車速），我們的系統能同時預測：
- **交通流量**：未來每5分鐘會有多少車輛通過
- **平均速度**：車輛的行駛速度會如何變化
- **交通密度**：道路的擁擠程度

**考慮時間與空間的複雜關係：**

交通狀況不只受「時間」影響（例如上下班時段），也受「空間」影響（前後路段互相影響）。我們的模型使用「時空注意力機制」，能夠：
- 分析不同時段的交通模式
- 考慮路段之間的相互影響
- 理解道路網絡的拓撲結構

**預測未來60分鐘：**

系統使用過去60分鐘的數據，預測未來60分鐘的交通狀況，每5分鐘更新一次預測。

### 3️⃣ 17種AI模型協同作戰

**為什麼需要這麼多模型？**

不同的AI模型各有所長：
- 有些擅長短期預測（5-15分鐘）
- 有些擅長長期預測（30-60分鐘）
- 有些擅長處理異常狀況
- 有些擅長正常流量預測

**模型分類：**

我們整合了三大類模型：

1. **圖神經網路家族**（6種）
   - 專長：理解道路網絡結構
   - 代表：DCRNN特別適合模擬震波傳播

2. **注意力機制模型**（2種）
   - 專長：捕捉關鍵影響因素
   - 代表：GMAN適合大範圍預測

3. **傳統時間序列模型**（9種）
   - 專長：穩定可靠的基準預測
   - 代表：ARIMA作為對照基準

**性能比較：**

在流量預測上，我們的MT-STNet模型表現最佳：
- MT-STNet：誤差12.3車輛/5分鐘（最佳）
- DCRNN：誤差13.8車輛/5分鐘
- LSTM：誤差17.9車輛/5分鐘
- ARIMA：誤差23.5車輛/5分鐘

### 4️⃣ RAG增強的AI助手

**什麼是RAG？**

RAG（Retrieval-Augmented Generation）是一種讓AI更聰明的技術：
- 傳統AI只能用自己「記住」的知識回答
- RAG會先「查詢」相關資料，再回答
- 就像學生考試可以翻書，答案會更準確

**我們的實現方式：**

1. **建立交通知識庫**
   - 收集所有歷史交通數據
   - 整理交通流理論、震波研究文獻
   - 儲存過去的管制案例與成效

2. **向量化知識**
   - 將所有知識轉換成向量（數字表示）
   - 儲存在ChromaDB向量數據庫
   - 可以快速搜尋相似的情境

3. **本地LLM推理**
   - 使用Ollama在本地運行大型語言模型
   - 採用qwen2.5:7b模型（70億參數）
   - 不需要連接外部API，保護隱私

**對話流程：**

當您問AI「現在國道1號北上有震波嗎？」
1. 系統先將問題轉換成向量
2. 在知識庫中搜尋相關資訊（即時數據、歷史案例）
3. 將搜尋到的資訊提供給LLM
4. LLM基於這些資訊生成回答
5. 回答會附上資料來源，可追溯

### 5️⃣ 混合預測架構

**兩種預測方法的結合：**

我們發現，最好的預測效果來自於結合兩種方法：

1. **傳統物理模型**
   - 基礎：交通流體力學理論
   - 優點：可解釋性強，符合物理規律
   - 缺點：無法處理複雜的異常情況

2. **深度學習模型**
   - 基礎：從大量數據中學習規律
   - 優點：能捕捉複雜模式
   - 缺點：黑盒子，難以解釋

**智慧融合策略：**

系統會根據不同情境，動態調整兩種方法的權重：
- 正常交通：深度學習權重70%，傳統方法30%
- 異常事件：傳統方法權重提高（更符合物理規律）
- 數據缺失：採用混合方法補足

**不確定性量化：**

系統不只告訴您預測結果，還會告訴您「有多確定」：
- 預測：30分鐘後車速降至50 km/h
- 信心度：85%（非常確定）
- 誤差範圍：±5 km/h

## 🚀 快速開始

### 您需要準備什麼

**基本環境：**
- 電腦：Windows 10以上、macOS 10.15以上、或Ubuntu 18.04以上
- 記憶體：至少8GB（建議16GB）
- 硬碟空間：至少10GB
- （可選）NVIDIA顯示卡：加速AI運算

**軟體需求：**
- Python 3.8以上版本
- Node.js 18以上版本
- Ollama（用於AI對話功能）

**API金鑰申請：**

您需要申請以下免費API：

1. **TDX交通資料平台**（必須）
   - 前往：https://tdx.transportdata.tw/
   - 註冊帳號並申請API金鑰
   - 提供台灣高速公路即時交通數據

2. **Google Maps API**（可選，用於地圖功能）
   - 前往：Google Cloud Console
   - 啟用Maps JavaScript API
   - 複製API金鑰

### 安裝步驟

#### 步驟一：下載專案

使用Git下載專案到您的電腦：

```bash
git clone https://github.com/ws97109/Highway_trafficwave.git
cd Highway_trafficwave
```

#### 步驟二：安裝Python套件

系統會自動安裝所有需要的Python套件：

```bash
pip install -r requirements.txt
```

這會安裝包括FastAPI（後端框架）、TensorFlow（深度學習）、pandas（數據處理）等43個套件。

#### 步驟三：安裝Ollama與AI模型

**macOS或Linux使用者：**

```bash
# 安裝Ollama
curl https://ollama.ai/install.sh | sh

# 下載AI模型（約4GB）
ollama pull qwen2.5:7b

# 啟動Ollama服務
ollama serve
```

**Windows使用者：**

請前往 https://ollama.ai 下載Windows版安裝程式，按照指示安裝即可。

#### 步驟四：設定環境變數

複製範例設定檔並填入您的API金鑰：

```bash
cp .env.example .env
nano .env  # 或用任何文字編輯器開啟
```

填入以下資訊：

```
# 交通數據API（必填）
TDX_CLIENT_ID=您的TDX帳號
TDX_CLIENT_SECRET=您的TDX密碼

# Google Maps API（選填）
GOOGLE_MAPS_API_KEY=您的Google Maps金鑰

# Ollama設定（預設值通常不需改）
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_REASONING_MODEL=qwen2.5:7b
```

#### 步驟五：安裝前端套件

進入前端目錄並安裝套件：

```bash
cd frontend
npm install
cd ..
```

#### 步驟六：（可選）建立AI知識庫

如果您想使用AI助手功能，需要先建立向量知識庫：

```bash
cd train_model
python build_vector_store.py
```

這個步驟會處理所有交通數據並建立向量索引，預計需要5-10分鐘。

### 震波檢測技術詳解

**為什麼交通震波像地震波？**

我們發現，交通震波的行為模式與地震波驚人地相似：

1. **向後傳播特性**
   - 地震波從震央向外傳播
   - 交通震波從壅塞點向後（上游）傳播
   - 都有固定的傳播速度

2. **波動形式**
   - 地震波是地殼的振動
   - 交通震波是車速的波動
   - 都可以用波動方程描述

3. **能量衰減**
   - 地震波越遠越弱
   - 交通震波也會逐漸消散
   - 都符合能量守恆定律

**檢測方法：**

我們在高速公路上設置了50個虛擬「測站」（類似地震站網）：

1. **多測站監控**
   - 持續監測每個測站的車速變化
   - 當某測站速度突然下降，開始追蹤
   - 確認後方測站是否依序出現速度下降

2. **傳播速度驗證**
   - 計算速度下降點在測站間的移動速度
   - 如果接近6.7 km/h，確認為震波
   - 如果速度不符，可能是其他因素（事故、施工等）

3. **嚴重程度分級**
   - 輕微：速度下降6-18 km/h
   - 中等：速度下降18-30 km/h
   - 嚴重：速度下降超過30 km/h

**準確度保證：**

我們的檢測系統經過嚴格驗證：
- 正確檢出率：91%（實際有震波，系統能檢測到）
- 精確率：84%（系統說有震波，真的有震波）
- 綜合準確率：87%
- 平均檢測時間：3.2秒

### MT-STNet深度學習技術

**模型的設計理念：**

想像一下，預測交通流量就像預測天氣：
- 需要考慮時間因素（早晚、工作日假日）
- 需要考慮空間因素（前後路段的相互影響）
- 需要考慮多個變數（流量、速度、密度）

我們的MT-STNet模型就是為此設計的。

**三層架構：**

1. **空間注意力層（理解路網結構）**

   這一層的任務是理解道路網絡的結構：
   - 哪些路段會互相影響？
   - 影響的強度有多大？
   - 是直接影響還是間接影響？

   例如：楊梅路段的壅塞，會影響到上游的中壢路段，也會影響到下游的湖口路段。但對更遠的台北路段影響就很小。

   模型會自動學習這些空間關係，不需要我們手動定義。

2. **時間注意力層（捕捉時間規律）**

   這一層專注於時間維度：
   - 工作日與假日的差異
   - 尖峰與離峰的模式
   - 季節性變化

   例如：週一早上8點的流量，與週六早上8點完全不同。模型會學習這些時間規律。

   同時，這一層還會分析「哪個歷史時間點」對「當前預測」最重要。比如預測未來30分鐘的流量，可能最近15分鐘的數據最關鍵，而1小時前的數據相對不重要。

3. **多任務輸出層（同時預測三項指標）**

   最後一層同時輸出三種預測：
   - 流量預測：未來會有多少車輛通過
   - 速度預測：車輛的行駛速度
   - 密度預測：道路的擁擠程度

   這三個指標互相關聯，一起預測比分開預測更準確。

**輸入與輸出：**

- **輸入**：過去12個時間點（60分鐘）的數據
  - 每個時間點包含：流量、速度、密度
  - 涵蓋所有50個測站
  - 總共：12時間點 × 50測站 × 3指標 = 1,800個數據點

- **輸出**：未來12個時間點（60分鐘）的預測
  - 同樣包含：流量、速度、密度
  - 同樣涵蓋所有50個測站
  - 總共預測：1,800個數據點

**訓練過程：**

模型使用了過去2年的歷史數據進行訓練：
- 訓練數據：2022-2023年的交通數據
- 驗證數據：2024年1-6月的數據
- 測試數據：2024年7-12月的數據

經過數百萬次的學習迭代，模型逐漸掌握了交通流的規律。

### 17種模型的協同合作

**為什麼需要這麼多模型？**

就像醫生看病，不同的專家各有專長：
- 內科醫生擅長內部疾病
- 外科醫生擅長手術治療
- 中醫擅長調理

AI預測模型也是如此，不同模型各有所長：

**第一類：圖神經網路（6個模型）**

這類模型的專長是理解網絡結構關係：

1. **DCRNN（擴散卷積循環網路）**
   - 專長：模擬震波在路網中的傳播
   - 原理：類似擴散方程，模擬震波如何在道路上傳遞
   - 適用：震波預測、異常事件傳播

2. **AGCRN（自適應圖卷積網路）**
   - 專長：自動學習路段之間的關係
   - 原理：不需要預先定義哪些路段相關，模型自己學
   - 適用：複雜路網、動態變化的交通模式

3. **Graph-WaveNet（圖波網）**
   - 專長：捕捉時空模式
   - 原理：結合時間序列與圖結構
   - 適用：長期預測、複雜交通模式

4. **ASTGCN（注意力時空圖卷積網路）**
   - 專長：同時考慮時間與空間的注意力
   - 原理：找出最關鍵的時間點與路段
   - 適用：多時段預測

5. **MTGNN（多任務圖神經網路）**
   - 專長：同時預測多個目標
   - 原理：共享底層特徵，分別預測不同指標
   - 適用：需要同時預測多種交通指標

6. **STGNN（時空圖神經網路）**
   - 專長：標準的時空預測
   - 原理：平衡時間與空間因素
   - 適用：一般交通預測場景

**第二類：注意力機制模型（2個模型）**

這類模型專注於找出關鍵影響因素：

1. **GMAN（圖多注意力網路）**
   - 專長：全局分析，看大範圍的影響
   - 原理：計算每個路段對其他所有路段的影響
   - 適用：大範圍、跨區域預測

2. **ST-GRAT（時空圖注意力網路）**
   - 專長：精細化分析每個路段
   - 原理：為每個路段量身定制預測策略
   - 適用：需要高精度的局部預測

**第三類：傳統時間序列模型（9個模型）**

這類模型雖然簡單，但穩定可靠：

1. **LSTM/BiLSTM（長短期記憶網路）**
   - 專長：記住長期的時間模式
   - 原理：選擇性地記憶重要的歷史資訊
   - 適用：時間序列預測的基準

2. **ARIMA/SARIMA（自回歸移動平均）**
   - 專長：捕捉週期性規律
   - 原理：統計學方法，分析時間序列的趨勢與週期
   - 適用：穩定的交通模式、基準比較

3. **SVR（支援向量回歸）**
   - 專長：處理非線性關係
   - 原理：找出最佳的非線性函數擬合數據
   - 適用：小數據集、非線性關係明顯的場景

**協同工作方式：**

系統會根據不同情境，選擇最適合的模型：

1. **正常交通**：使用MT-STNet作為主力
2. **震波傳播**：DCRNN表現更好
3. **異常事件**：結合傳統模型與深度模型
4. **數據缺失**：使用魯棒性更強的ARIMA

最終預測可以是：
- 單一模型（信心度高時）
- 多模型融合（不確定時取平均）
- 加權融合（根據歷史表現加權）

### RAG AI助手技術原理

**什麼是RAG？**

RAG的全名是 Retrieval-Augmented Generation（檢索增強生成），可以拆解為三個步驟：

1. **Retrieval（檢索）**：先找相關資料
2. **Augmented（增強）**：用資料增強提示
3. **Generation（生成）**：生成回答

**為什麼需要RAG？**

傳統的AI聊天機器人有個問題：只能用「訓練時學到的」知識回答，無法使用最新資訊。

比如：
- ❌ 傳統AI：「請問現在國道1號有震波嗎？」→ AI不知道，因為它沒有即時數據
- ✅ RAG AI：先查詢資料庫，找到最新數據，再回答

**我們的實現方式：**

**步驟一：建立知識庫**

我們將所有相關資料整理成知識庫：
- 所有歷史交通數據（2020-2024年）
- 交通流理論文獻
- 震波研究論文
- 過去的管制案例與效果
- 常見問題解答

總共約100萬筆知識條目。

**步驟二：向量化**

將所有知識轉換成向量（一串數字）：
- 每個句子或段落轉成一個向量
- 例如「國道1號楊梅段經常發生震波」→ [0.2, 0.8, 0.3, ...]
- 相似的內容會有相似的向量
- 儲存在ChromaDB向量數據庫

**步驟三：語義搜尋**

當用戶提問時：
1. 問題也轉成向量
2. 在向量庫中找最相似的向量
3. 找出最相關的5-10個知識片段

例如，問「為什麼楊梅路段一直塞車？」：
- 相似度95%：楊梅路段歷史震波數據
- 相似度88%：上坡路段壅塞研究
- 相似度82%：匝道設計影響
- 相似度75%：類似路段改善案例

**步驟四：組合提示**

將檢索到的資料與問題組合：

```
【相關資料】
1. 楊梅路段2024年1-3月發生138次震波...
2. 該路段為上坡路段，坡度3-5%...
3. 類似問題在國道3號土城段也出現過...

【用戶問題】
為什麼楊梅路段一直塞車？

【請根據以上資料回答】
```

**步驟五：LLM生成回答**

將組合好的提示傳給Ollama的qwen2.5:7b模型：
- 模型閱讀提供的資料
- 理解問題的意圖
- 基於資料生成回答
- 附上資料來源

**優勢：**

1. **準確性**：回答有根據，不是瞎猜
2. **可追溯**：顯示資料來源，可驗證
3. **即時性**：可查詢最新數據
4. **專業性**：整合專業知識庫
5. **隱私性**：全部在本地運行，不上傳雲端

### 混合預測策略

**兩種預測哲學：**

預測交通流量有兩種截然不同的方法：

**方法一：傳統物理模型**

基於交通流體力學理論，認為交通流動遵循物理定律：
- 流量 = 密度 × 速度（基本方程）
- 有震波方程描述震波傳播
- 有排隊理論描述壅塞形成

優點：
- 可解釋性強：每一步都知道為什麼
- 符合物理規律：不會出現違反常識的預測
- 穩定可靠：不會因為數據變化而失效

缺點：
- 假設太多：實際交通比理論複雜
- 無法處理異常：突發事件難以建模
- 參數調整困難：不同路段需要不同參數

**方法二：深度學習模型**

讓AI從大量數據中自己學習規律：
- 不需要假設交通如何運作
- 從歷史數據中發現隱藏的模式
- 能處理非常複雜的非線性關係

優點：
- 能捕捉複雜模式：包括人類難以察覺的規律
- 自適應：自動適應不同路段、不同時段
- 高準確度：在大數據情況下表現優異

缺點：
- 黑盒子：不知道為什麼這樣預測
- 需要大量數據：數據少時表現不佳
- 可能過度擬合：記住了數據而非規律

**我們的混合策略：**

既然兩種方法各有優缺點，為什麼不結合兩者的優勢？

**策略一：加權平均**

最簡單的方法，將兩種預測加權平均：
- 預測結果 = 30% × 傳統模型 + 70% × 深度學習
- 權重可以根據實際表現調整
- 穩定且易於理解

**策略二：自適應融合**

根據當前情境動態調整權重：

正常情況（信心度高）：
- 深度學習權重：80%
- 傳統方法權重：20%
- 因為深度學習在正常情況下更準確

異常情況（突發事件）：
- 深度學習權重：40%
- 傳統方法權重：60%
- 因為傳統方法更符合物理規律，更可靠

數據缺失（測站故障）：
- 深度學習權重：30%
- 傳統方法權重：70%
- 因為深度學習需要完整數據

**策略三：情境選擇**

根據不同情境選擇不同模型：

| 情境 | 選擇模型 | 原因 |
|------|---------|------|
| 正常尖峰時段 | MT-STNet | 模式穩定，深度學習最準 |
| 異常事件 | 物理模型 | 符合因果關係，可信賴 |
| 假日出遊 | SARIMA | 週期性明顯，統計方法適合 |
| 數據不完整 | 混合方法 | 互補不足 |

**不確定性量化：**

我們不只給預測值，還會告訴您有多確定：

例如：
- 預測30分鐘後車速：65 km/h
- 信心區間：60-70 km/h（90%信心度）
- 意思：我們有90%的把握，實際車速會在60-70之間

這讓使用者知道：
- 什麼時候可以信任預測
- 什麼時候要保持警惕
- 什麼時候需要準備備案

**Q6：為什麼選擇地震學理論？**

- 都可以用波動方程描述
- 都可以通過測站網絡監測

- 有些擅長正常狀況
- 有些擅長異常事件

多模型協同，可以在各種情境下都有最佳表現。
